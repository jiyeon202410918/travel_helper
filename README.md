한국 지도를 클릭하면 지역별 놀거리 추천과 함께 날씨 정보, 옷차림 이미지까지 보여주는 파이썬 GUI 프로그램입니다.

## 주요 기능
- 지역 버튼 기반 GUI (tkinter)
- OpenWeather API로 날씨 실시간 연동
- 기온에 따라 옷차림 텍스트 + 랜덤 이미지 추천
- 데이터 구조 분리 및 깔끔한 코드 설계

## 사용법

1. `main.py` 실행
2. 지도에서 지역 클릭
3. 추천 놀거리 선택
4. 날씨 + 코디 정보 확인!
